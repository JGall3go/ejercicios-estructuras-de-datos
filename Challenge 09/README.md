# Challenge 09 - Árbol n-ario

- Árbol n-ario (`src/estructuras/ArbolNario.js`) con el código de la diapositiva: `Nodo` con `agregarHijo`, y los recorridos `dfs` y `bfs`.
- En `src/menu.js` se llena el árbol con menús y submenús. Cada item tiene título, link y componente.
- El menú lateral se pinta recorriendo el árbol con el componente recursivo `ItemMenu`. Los menús con hijos se abren y cierran al darles clic.
- Al dar clic en un item se muestra su componente a la derecha.
- Los recorridos DFS y BFS se imprimen en la consola.

## Cómo correrlo

```
npm install
npm run dev
```
