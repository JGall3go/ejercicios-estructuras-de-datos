# Challenge 05 - Colas

- Cola de personas en un cajero (`src/estructuras/Cola.js`). Cada persona tiene nombre, monto a retirar y una fecha de llegada aleatoria que pone el sistema.
- La cola empieza con 4 personas de prueba.
- Formulario para crear una persona nueva y agregarla a la cola.
- La cola se muestra en pantalla ordenada por la fecha de llegada.

## Cómo correrlo

```
npm install
npm run dev
```
