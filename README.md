# Challenge 04 - Pilas

- Pila de libros (`src/estructuras/Pila.js`). Cada libro tiene nombre, ISBN, autor y editorial.
- La pila empieza con 3 libros de prueba.
- Formulario para crear un libro nuevo y agregarlo a la pila.
- La pila se muestra en pantalla con el último libro agregado arriba.

## Cómo correrlo

```
npm install
npm run dev
```
