# Challenge 08 - Árbol binario

- Árbol binario de búsqueda (`src/estructuras/ArbolBinario.js`), con el código de la diapositiva: `insertar`, `preorden`, `inorden` y `postorden`.
- Se insertan los números 50, 30, 70, 20, 40, 60, 80, 35, 65, 90 y se imprimen los tres recorridos por consola.
- Método `buscar(valor)` para saber si un valor está en el árbol, con un formulario en pantalla.
- El árbol se dibuja con `react-d3-tree`. Como esa librería pide los datos con la forma `{ name, children }`, la función `convertirParaD3` pasa el árbol a esa forma.

## Cómo correrlo

```
npm install
npm run dev
```
